GITHUB UPLOAD

This package is already arranged so that the contents of this folder should be uploaded directly to the ROOT of your GitHub repository.

Important:
- index.html must remain in the repository root.
- Keep all folders (admin, assets, courses, batches, notices, etc.) in their existing positions.
- Do not put this entire folder inside another folder in the repository.
- If using GitHub Pages, set the publishing source to the repository root (/).
